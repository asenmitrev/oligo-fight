# OLIGO FIGHT

A local 2-player fighting game built in Godot 3.

## Running the Game

Open `project.godot` in Godot Engine 3.x and press Play.

## Controls

| | Player 1 | Player 2 |
|---|---|---|
| Left | ← / D-pad | A |
| Right | → / D-pad | D |
| Jump | ↑ / D-pad | W |
| Down | ↓ / D-pad | S |
| Punch | K | F |
| Kick | L | G |

Gamepad is supported for both players (Player 1 = controller 0, Player 2 = controller 1).
